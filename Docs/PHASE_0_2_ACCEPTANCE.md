## 승인 관문 A — Simulator와 단위 테스트

- [ ] `GoHome` scheme이 iOS 17 이상 Simulator용으로 빌드된다.
- [ ] `GoHomeTests`의 기존 테스트와 Phase 1·2 신규 테스트가 모두 통과한다.
- [ ] 앱이 시작되고 위치 권한 요청 전 화면과 수동 역 검색 화면이 표시된다.
- [ ] 비밀 설정이 비어 있어도 앱은 시작되며 도착정보만 설정 안내를 표시한다.

명령줄 검증이 가능한 전체 Xcode 환경에서는 다음 빌드부터 실행한다.

```sh
xcodebuild \
  -project GoHome.xcodeproj \
  -scheme GoHome \
  -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO \
  build
```

단위 테스트는 Xcode의 Product → Test에서 `GoHomeTests`를 실행한다. 설치된 Simulator 이름이
확정되면 같은 scheme을 대상으로 `xcodebuild test`를 실행해도 된다.

## 승인 관문 B — 실제 iPhone 위치 시나리오

- [ ] Personal Team으로 실제 iPhone에서 앱이 실행된다.
- [ ] 정확한 위치 허용: 가까운 역 상위 3개와 거리 순서가 실제 위치와 맞는다.
- [ ] 대략적 위치 허용: 대략적 위치 안내가 표시되고 수동 검색으로 역을 바꿀 수 있다.
- [ ] 위치 거부/제한: 가까운 역 대기 화면 대신 수동 검색 안내가 표시된다.
- [ ] 지원 역 5km 밖: 범위 밖 안내가 표시되고 자동 선택은 해제된다.
- [ ] 범위 밖에서도 수동 선택한 역과 도착정보는 유지된다.
- [ ] `신촌`, `양평` 등 동명이역 검색 결과가 노선명으로 구분된다.
- [ ] `평택지제역`, `지제`, `2호선`처럼 역명·API 별칭·노선명 검색이 동작한다.

## 승인 관문 C — 실제 도착정보 비교

- [ ] 앱 전면에서 첫 조회 후 약 40초 간격으로 갱신된다.
- [ ] 백그라운드 전환 후 자동 요청이 멈추고 전면 복귀 시 재개된다.
- [ ] 자동 갱신 중 수동 새로고침을 실행해도 중복 요청·목록 깜빡임이 없다.
- [ ] 네트워크 실패 시 마지막 정상 목록과 마지막 정상 갱신시각이 유지된다.
- [ ] 2분 이상 지난 `recptnDt` 데이터에 오래된 정보 경고가 표시된다.
- [ ] 환승역에서 동일 역명의 다른 호선 데이터가 올바르게 분리된다.
- [ ] 실제 역 전광판과 방향·종착역·열차 순서를 비교해 일치 여부를 기록한다.

최소 비교 권장 표본은 환승역 1곳, 단일 노선 역 1곳, 동명이역 또는 개명 역 1곳이다. 원천 API
수신시각과 전광판 갱신시각 차이가 있으므로 비교 시 앱의 `데이터 기준` 시각도 함께 기록한다.
