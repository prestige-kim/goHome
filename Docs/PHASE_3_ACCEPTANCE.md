# Phase 3 최종 승인 검증표

Phase 3 실시간 열차 위치의 코드·정적 데이터·Worker 구현은 완료했다. 이 문서는 현재 환경에서
실행한 검증과 전체 Xcode·iPhone이 필요해 보류한 승인 검증을 구분한다. 보류 항목을 실행하기
위해 Xcode 설치를 요구하거나 자동 설치하지 않는다.

## 현재 완료된 검증

- [x] `main`과 `origin/main` 동기화 확인 후 작업 시작
- [x] Worker `/v1/positions?line=` Bearer 인증과 19개 노선 allowlist
- [x] 임의 URL·호스트 입력 차단과 원본 키·URL 비노출 오류 응답
- [x] Worker 회귀 테스트 12개 통과
- [x] 기존 Free 플랜 Worker 재배포
- [x] 2026-08-19 HTTPS 종단간 호출: 무인증 401, 시청 도착 14건, 2호선 위치 35건, `INFO-000`
- [x] 실제 위치 DTO 13개 필드와 상태 코드 0·1·2 관측, 공식 코드 3 매핑 테스트
- [x] 19개 노선·28개 명시적 경로 생성 및 696개 역-노선 매핑 전체 검증
- [x] 지선·분기·순환선·GTX-A 미연결 구간과 원거리 오연결 자동 검증
- [x] Swift 소스 전체 `swiftc -parse` 통과
- [x] Xcode 프로젝트 파일 `plutil -lint` 통과
- [x] Xcode 26.6·iPhone 17 Pro Simulator Debug 빌드 통과
- [x] Simulator `GoHomeTests` 33개 전체 통과
- [x] 1호선 실응답 81행·72개 열차 중 중복 열차번호 9개 관측 및 최신 수신시각 선택 검증
- [x] Simulator에서 서울시청 가상 위치 기준 가까운 역과 실제 Worker 도착정보 표시 확인
- [x] 시청역 1·2호선 위치 UI에서 현재 역·상태·방향·종착역·급행·남은 역 수 확인
- [x] 노선·방향별 가까운 열차 최대 3대 제한과 GPS 좌표 아님 안내의 접근성 텍스트 확인
- [x] Simulator 전면에서 약 42초 후 자동 갱신, 백그라운드 52초 이상 중지, 복귀 직후 재개 확인

이전에 Command Line Tools compiler와 SDK 버전 차이로 실행하지 못했던 전체 타입 검사는 실제
Xcode 빌드와 XCTest 통과로 대체 검증했다.

## 전체 Xcode 승인 검증

- [x] iOS 17 이상 Simulator에서 `GoHome` Debug 빌드 성공
- [x] `GoHomeTests` 전체 통과
- [x] 위치 DTO 0/1/2/3, 일반/급행/특급, 막차 표시 테스트 통과
- [x] 선형·분기·2호선 순환·종착역 제한의 남은 역 수 테스트 통과
- [x] 동시 수동/자동 갱신이 도착·위치 요청을 중복 실행하지 않음
- [x] 위치 요청 실패 후 노선별 마지막 정상 데이터와 오래된 상태 유지

## 실제 iPhone·역 현장 승인 검증

- [ ] 선택 역의 모든 호선 위치 요청과 노선별 부분 실패 UI 확인
- [ ] 앱 전면 40초 갱신, 백그라운드 전환 즉시 중지, 복귀 후 재개 확인
- [ ] 현재 역·상태·방향·종착역·급행/특급·막차·남은 역 수 레이아웃 확인
- [ ] Dynamic Type과 VoiceOver에서 노선 스트립 정보가 이해 가능함
- [ ] 화면에 GPS 좌표가 아닌 현재 역 기반 정보라는 안내가 항상 보임
- [ ] 실제 전광판과 1·2·5·6호선 및 경의중앙선 분기 사례 비교
- [ ] 불일치 시 열차번호, 현재 역, 종착역, 방향, 앱/전광판 시각만 기록하고 비밀값은 기록하지 않음

Simulator 수명주기 검증에서는 마지막 정상 갱신이 `오후 5:15:18`에서 `오후 5:16:00`으로
변경되는 것을 확인했다. Home 화면으로 전환한 뒤 52초 이상 유지하고 복귀한 직후에는 이전 값
`오후 5:16:42`가 그대로였으며, 전면 복귀 직후 `오후 5:19:03`으로 갱신됐다. 실제 iPhone의
운영체제 스케줄링과 네트워크 조건은 별도이므로 위 실제 기기 항목은 완료 처리하지 않는다.

## 합격 기준

선택 역으로 접근하는 열차의 현재 역 또는 상태와 남은 역 수를 사용자가 이해할 수 있고, 분기상
선택 역을 통과하지 않는 열차가 섞이지 않으며, 실패·지연 데이터가 최신 GPS 위치처럼 보이지
않아야 한다.
