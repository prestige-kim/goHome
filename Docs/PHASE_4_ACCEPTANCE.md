기준일: 2026-08-21
대상 브랜치: `main`

## 현재 판정

Phase 4의 Worker·앱 코드와 Simulator 승인 항목은 구현·검증됐다. 네 영업일 선택과 공휴일 폴백
경고를 실제 화면에서 확인했고, 강남·고속터미널 원본 시간표도 앱과 같은 축약 규칙으로 대조했다.
접근성 대형 글자에서 발견한 레이아웃 문제도 수정했다. 다만 별도 공공데이터포털 키가 미설정이고
실제 iPhone이 연결되지 않아 공휴일 실호출·실기기·현장 승인까지 포함한 최종 승인은 남아 있다.

- [x] `오늘`, `평일`, `토요일`, `일·공휴일` 선택을 각각 전환

- [x] 접근성 대형 글자에서 상단·섹션·막차 행 적응형 레이아웃 확인
- [x] 접근성 트리에서 역 선택→상태→갱신→노선→열차 순서와 결합된 막차 행 확인
- [ ] 실제 VoiceOver 제스처·음성 읽기 확인

단일 노선인 광화문역을 선택해 영업일 메뉴를 안정적으로 노출한 뒤 네 선택지를 모두 전환했다.
`오늘` 선택에서는 공휴일 확인 실패 경고와 평일 폴백이 표시됐고, 토요일과 일·공휴일은 동일한
주말 원본이 서로 명확한 선택값으로 표시됐다. 네트워크 전체 차단은 실행 환경에 영향을 주므로
재현하지 않았고 마지막 정상 데이터 유지는 단위 테스트 결과만 승인했다.

## 알려진 제한

- 서울교통공사 시간표 원본은 평일/주말만 구분한다. 앱은 사용자의 선택을 명확히 보여주지만
  토요일과 일요일/공휴일은 현재 동일한 원본 주말 시간표를 사용한다.
- 막차 영역은 실시간 위치가 아니라 예정 운행시각표다. 운행 변경이나 현장 상황과 다를 수 있다.
- 공공데이터포털 키가 없거나 공휴일 API가 실패하면 달력 요일 기준으로 동작하며 경고를 표시한다.
- 시간표 자동 조회는 역 선택·영업일 선택·앱 전면 진입 때 수행하고 40초 실시간 갱신에는 합치지
  않아 서울시 요청을 불필요하게 반복하지 않는다.

## 승인 완료 조건

다음 항목을 모두 충족하면 Phase 4를 최종 승인한다.

1. 공휴일 API 실제 종단간 호출이 통과한다.
2. 실제 VoiceOver와 네트워크 실패 UI 조작 항목이 통과한다.
3. 실제 iPhone에서 전면/백그라운드와 자정 전후 표시가 안정적으로 동작한다.
4. 실제 역 게시 시간표 또는 전광판과 주요 환승역 표시가 일치한다.
