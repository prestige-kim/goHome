# Phase 4 막차 승인 검증표

기준일: 2026-08-20  
대상 브랜치: `main`

## 현재 판정

Phase 4의 Worker·앱 코드와 자동 검증은 구현됐다. 서울시 키 교체 후 배포 Worker를 다시 검증했고,
서울교통공사 실제 시간표 호출과 iPhone Simulator 빌드·XCTest도 통과했다. Simulator 막차 목록의
실제 표시까지 확인했지만 공휴일 API 실호출, 영업일 선택·오류 UI 조작, 주요 환승역 표시값의
공식 시간표 행 단위 비교가 남아 있으므로 Phase 4 전체를 최종 승인으로 표시하지 않는다.

## 실제 API·Worker 검증

- [x] 현재 `getTrainSch`에서 시청역 1호선 `0151`, 2호선 `0201` 확인
- [x] 역 ID 숫자를 시간표 코드나 노선 순서로 추정하지 않음
- [x] 배포 Worker `/health` HTTP 200 확인
- [x] 무인증 `/v1/last-trains` HTTP 401 확인
- [x] Bearer 인증 후 시청역 2호선 내선 HTTP 200·원본 코드 `00` 확인
- [x] 실제 시간표 행 239건과 역·호선·방향·출발시각·종착역 필드 확인
- [x] 키 교체 후 기존 Free 플랜 Worker 재배포·종단간 재검증
- [x] 시청·강남 2호선 내선 239행·외선 240행, 필수 필드·시간 형식 오류 0행
- [x] 고속터미널 3호선 상·하행 각 192행, 필수 필드·시간 형식 오류 0행
- [x] 공휴일 Secret 미설정 오류가 원본 URL·키를 노출하지 않음을 확인
- [ ] `PUBLIC_DATA_API_KEY` 설정 후 실제 `/v1/service-day` 평일 응답 확인

배포 주소는 기존 Cloudflare Workers Free 플랜의 기본 `workers.dev` 주소를 유지한다. 새 유료
서비스·데이터베이스·도메인은 추가하지 않았다.

- [x] Phase 4 앱 설치와 실행
- [x] 시청역에서 실제 위치·도착정보가 기존 Home 디자인에 표시됨

- [x] 화면을 아래로 스크롤해 막차 섹션의 방향·종착역·시간·남은 시간 육안 확인
- [x] 자정 이후 시간의 `(+1일)`과 `예정 시간표` 표기 확인
- [x] 토·일/공휴일이 동일한 주말 시간표를 사용한다는 안내와 GPS 위치 비해당 안내 확인
- [ ] `오늘`, `평일`, `토요일`, `일요일/공휴일` 선택을 각각 전환
- [ ] 공공데이터 키 미설정 상태의 공휴일 폴백 경고 확인
- [ ] 네트워크 실패 후 마지막 정상 막차표 유지 안내 확인
- [ ] 큰 글자 크기와 VoiceOver 읽기 순서 확인

Simulator 자동 제어로 막차 목록까지 스크롤하고 접근성 설명과 화면을 함께 확인했다. 다만 긴
목록의 영업일 선택 영역을 안정적으로 다시 노출해 네 선택지를 전환하거나 네트워크 오류를
재현하지는 못했으므로 해당 항목은 완료로 표시하지 않았다.

## 실기기·현장 승인

- [ ] Personal Team으로 실제 iPhone 설치
- [ ] 전면에서 막차 조회 후 백그라운드 전환 시 불필요한 반복 요청이 없는지 확인
- [ ] 자정 전후와 오전 4시 전후 표시 확인
- [ ] 시청 외 주요 환승역 2곳 이상에서 공식 시간표와 방향·종착역·막차 시각 비교
- [ ] 실제 실시간 막차 열차 표식과 예정 시간표가 혼동되지 않는지 확인

## 알려진 제한

- 서울교통공사 시간표 원본은 평일/주말만 구분한다. 앱은 사용자의 선택을 명확히 보여주지만
  토요일과 일요일/공휴일은 현재 동일한 원본 주말 시간표를 사용한다.
- 막차 영역은 실시간 위치가 아니라 예정 운행시각표다. 운행 변경이나 현장 상황과 다를 수 있다.
- 공공데이터포털 키가 없거나 공휴일 API가 실패하면 달력 요일 기준으로 동작하며 경고를 표시한다.
- 시간표 자동 조회는 역 선택·영업일 선택·앱 전면 진입 때 수행하고 40초 실시간 갱신에는 합치지
  않아 서울시 요청을 불필요하게 반복하지 않는다.

## 승인 완료 조건

다음 항목을 모두 충족하면 Phase 4를 최종 승인한다.

1. 공휴일 API 실제 종단간 호출이 통과한다.
2. Simulator 막차 섹션 수동 조작 항목이 통과한다.
3. 주요 환승역 공식 시간표 비교에서 방향·종착역·시각이 일치한다.
4. 실제 iPhone에서 전면/백그라운드와 자정 전후 표시가 안정적으로 동작한다.
